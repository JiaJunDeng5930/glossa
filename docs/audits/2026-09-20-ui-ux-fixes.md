## 交互取舍

重复制卡确认采用非模态交互，让读者仍可操作原网页；焦点已经移到网页时，确认框的异步关闭不会把它抢回。选择提示的位置调整保留了原有按住快捷键的手势。

只有实际被截断的释义才出现展开入口，避免密集文章充满冗余按钮和 Tab 停靠点。原文链接与释义入口分别处理激活；展开内容位于现有 Shadow DOM 中，以免进入宿主文本和后续扫描。窗口、字体或外观变化后重新判断截断，页面清理同时解除观察和展开状态。

截断测量按帧批量进行，并分开样式写入、布局读取和结果更新，避免逐词同步测量挤占原页面扫描的时间预算。

设置页的字段提示复用现有校验规则的字段信息，避免界面与保存端使用不同规则。加载、保存和各连接操作继续分别表达自己的状态；编辑错误不会解锁无关的进行中操作。

最终独立审查发现，搜索重绘曾提前重新启用正在清空词汇的按钮。现已让搜索只负责列表呈现，由串行数据刷新更新清空入口，并增加延迟清空期间搜索与取消搜索的回归检查。
